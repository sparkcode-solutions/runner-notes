Runner notes is an app that uses apple note format for recording pace and record runner high journals


As as a low to moderate runner , I like running but I want like my own little version of notes where it uses similar to starva to track and record pace , so I open runner notes app , it is basically a note app similar to apple notes , it would have a folder page where on each folder it would contain a run moment . 

Run moment - run moment is a run session , every run session counts as a run moment , under each run moment there would be run journals , run pace , run photos , run memos making each session a valuable session . 

How to create a run moment ? 

I open the app , then I click on a new run button , once I open it it ask for a trail (manual for now), we then start the run and start running , it is similar to starva in this feature meaning it would calculate pace , user could pause the run , stop the run , in doing the run , they could take run snap , run memos (voice recordings) , run journals 

- the theme of the app to create each run as a moment because I myself love running , basically the UI is gonna be similar to apple notes but should not exactly be the same .
